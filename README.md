# Cat Solitaire for Aunica

[Play Cat Solitaire](https://steadystategames.dev/Cat-Solitaire/)

Tommy, Cinnamon and Shrimpy star in an ad-free portrait puzzle game. Tap Xs, swipe from a blank square to mark or from an X to erase, and hold to place a cat; on desktop, right-click places cats and Ctrl+Z undoes. Puzzles and Daily keep separate progress. Normal and Hard offer 5x5 through 10x10 puzzles. Normal allows unlimited revisions and earns one print per cat, doubled without Treats. Hard has trickier deductions and three lives; wrong attempts leave the square unchanged, and correct placements celebrate with a chime and sparkles; each remaining life earns 5 prints and 1 heart. Daily adds 3 prints and 1 heart. A peanut-butter dog-bone cracker icon marks Treats, which cost 3 prints on Normal/Daily or 5 on Hard; tutorial Treats are free. Enable the optional shuffled color checklist in Settings; with it hidden, a cat icon shows the remaining count. Buy permanent accessories with prints or hearts in Settings > Wardrobe. Notes, Undo, lives, prints, hearts and outfits save in this browser.

The wardrobe has nine illustrated accessories with three cat-specific styles each, including berets, wizard hats, sun hats, moon tiaras and deluxe star crowns. Try on any item for free before buying; purchases unlock only the selected cat's accessory. Paw-print and heart icons show prices and balances, with currency sprites flying into the purchase or Treat button as the balance decreases. The catalog scrolls by touch or mouse wheel while the cat preview stays visible.

Puzzle generation includes three-square lines, small Ls and 2x2 blocks, with fewer two-square colors. All sizes have verified fallback puzzles that preserve uniqueness and supported deductions.

This fresh-start update resets earlier progress once: old boards, wins, currency and outfits start over. New progress saves normally afterward. Audio preferences remain.

This repository contains the tested Godot web export. It is published from `main` through GitHub Pages. Godot Engine is distributed under the included MIT license.
