# Cat Solitaire for Aunica

[Play Cat Solitaire](https://steadystategames.dev/Cat-Solitaire/)

Tommy, Cinnamon and Shrimpy star in an ad-free portrait puzzle game. Tap or swipe Xs, hold to place a cat; on desktop, right-click places cats and Ctrl+Z undoes. Puzzles and Daily keep separate progress. Normal and Hard offer 5x5 through 10x10 puzzles. Normal allows unlimited revisions and earns one print per cat, doubled without Treats. Hard has trickier deductions and three lives; each remaining life earns 5 prints and 1 heart. Daily adds 3 prints and 1 heart. Enable the optional color checklist in Settings. Buy permanent accessories with prints or hearts in Settings > Wardrobe. Notes, Undo, lives, prints, hearts and outfits save in this browser.

The wardrobe has nine illustrated accessories with three cat-specific styles each, including berets, wizard hats, sun hats, moon tiaras and deluxe star crowns. Try on any item for free before buying; one purchase unlocks all three styles. The catalog scrolls by touch or mouse wheel while the cat preview stays visible.

This repository contains the tested Godot web export. It is published from `main` through GitHub Pages. Godot Engine is distributed under the included MIT license.
