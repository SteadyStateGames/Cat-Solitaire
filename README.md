# Purrsonal Space

[Play Purrsonal Space](https://steadystategames.dev/purrsonalspace/) or [catpuzzle](https://steadystategames.dev/catpuzzle/).

Tommy, Cinnamon and Shrimpy star in a cozy cat logic puzzle. Place one cat in each row, column and color, with no touching cats.

Story follows seeded levels and earns prints and hearts, with picture-only comics every five levels. Free Play offers Easy and Standard without spending or earning currency. Daily is a shared 7x7, 8x8 or 9x9 challenge with triple rewards. Choose a centered PC layout or a phone layout before playing, and switch in Settings.

Treat hints use visible deductions; Why explains the selected proof with a numbered board diagram. Wardrobe is directly accessible from the game, with free try-on and permanent accessories for each cat. Purchases and equipping have animations and distinct sounds. Progress and preferences save locally, and the game works offline after caching.

This repository contains the tested Godot web export, published from main through GitHub Pages. Godot Engine is distributed under the included MIT license.
