# Cat Solitaire for Aunica

[Play Cat Solitaire](https://steadystategames.dev/Cat-Solitaire/)

Tommy, Cinnamon and Shrimpy star in an ad-free portrait puzzle game. Tap to mark an X, swipe to mark several squares, and hold to place a cat. A whole swipe is one Undo. Help contains rule demonstrations and a short practice puzzle; Settings contains audio, puzzle sizes and earned outfits. All three cats always play. Progress saves in this browser.

This repository contains the tested Godot web export. It is published from `main` through GitHub Pages. Godot Engine is distributed under the included MIT license.
