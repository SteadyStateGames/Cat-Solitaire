# Cat Solitaire for Aunica

[Play Cat Solitaire](https://steadystategames.dev/Cat-Solitaire/)

Tommy, Cinnamon and Shrimpy star in an ad-free portrait puzzle game. Tap or swipe Xs, hold to place a cat; on desktop, right-click places cats and Ctrl+Z undoes. Puzzles and Daily keep separate progress. Earn paw prints by solving: one per cat, doubled without Treats, plus 3 for a daily. Buy permanent accessories in Settings > Wardrobe. Notes, Undo, paw prints and outfits save in this browser.

This repository contains the tested Godot web export. It is published from `main` through GitHub Pages. Godot Engine is distributed under the included MIT license.
